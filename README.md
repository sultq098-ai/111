# Dota 2 — вызов в пати

Интерактивное шуточное приглашение другу: три ластхита, допуск в пати и копирование ответа. Тёмный терминальный стиль, адаптация для телефона, управление пробелом или нажатием. Звук включается отдельно.

Открой index.html в браузере. Сборка не нужна. Для GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

Ответы не отправляются и не сохраняются автоматически. Фанатская страница, не связанная с Valve.

# Pink date — Гульдана ♡

Розовая игра-приглашение: найди четыре пары карточек и открой приглашение на встречу.

## Запуск
Открой `index.html` в браузере. Сборка и установка зависимостей не требуются.

Для публикации через GitHub Pages выбери в Settings → Pages источник Deploy from a branch, ветку main и папку / (root).

В конце игры ответ можно скопировать и отправить вручную. Сайт сам не отправляет сообщения и не сохраняет ответы.
